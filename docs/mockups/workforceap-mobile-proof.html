The mobile rules baked into the system

  • Member: bottom tab nav (Journey/Program/Jobs/Me), gradient hero + ring scale down, stat tiles go 2-col.
  • Staff (admin/counselor/employer): sidebar collapses to a hamburger drawer (already live in the admin full build).
  • Charts: stack vertically, bars stay readable, KPI strips go 2-col.
  • Wide tables / CSV rosters: become stacked cards on mobile — no horizontal squish, the row's key fields surface as a mini-card.
