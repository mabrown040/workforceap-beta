### Phase Details

| Phase | Name | Icon | Description | Key Activities |
|-------|------|------|-------------|----------------|
| **1** | **Discover** | 🔍 | Member learns about program | Browse programs, eligibility check, info session |
| **2** | **Apply** | 📝 | Formal application submitted | Application form, document upload, initial screening |
| **3** | **Assess** | 📊 | Skills & fit evaluation | Aptitude tests, career readiness assessment |
| **4** | **Enroll** | 🎓 | Program acceptance & onboarding | Orientation, cohort assignment, goal setting |
| **5** | **Train** | 📚 | Core curriculum completion | Technical training, soft skills, projects |
| **6** | **Certify** | 🏆 | Industry credential earned | Certification exams, portfolio development |
| **7** | **Prepare** | 💼 | Job search readiness | AI resume builder, interview practice, LinkedIn |
| **8** | **Match** | 🔗 | Candidate-employer pairing | Job matching algorithm, counselor recommendations |
| **9** | **Interview** | 🎯 | Interview coordination | Mock interviews, scheduling, feedback loops |
| **10** | **Placement** | ✅ | Job offer acceptance | Offer negotiation, acceptance, onboarding |
| **11** | **Support** | 🤝 | 90-day post-placement care | Check-ins, coaching, retention support |

### Alert System

| Flag Level | Trigger | Action Required |
|------------|---------|-----------------|
| 🔴 **Critical** | No activity 10+ days, missed milestone, dropout risk | Immediate counselor contact within 24h |
| 🟡 **Warning** | Declining performance, late submissions, 5+ days no contact | Check-in within 48h, adjust plan |
| 🟢 **On Track** | Meeting milestones, regular engagement | Standard support, celebrate wins |
| 🔵 **Milestone** | Phase completion, certification earned | Recognition, next phase prep |

### Logo Usage

**Primary Logo**: Use `logo-tight.svg` for presentations and documents
- Minimum clear space: 20px on all sides
- Do not distort, rotate, or apply effects to logo
- On dark backgrounds, use the white version

### Presentation Templates

When creating slides or documents for CEO presentations:

1. **Background**: Use `#1a1a1a` (near-black) for hero slides, `#ffffff` for content
2. **Accent elements**: Use crimson (`#ad2c4d`) for emphasis and CTAs
3. **Data visualization**: Use the full palette with gold for highlights
4. **Icons**: Use Lucide icons or similar clean, outlined style
5. **Spacing**: Maintain 8px grid system, generous whitespace
