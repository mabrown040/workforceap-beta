  `Application` / `MessageThread` are not in `TENANT_SCOPED_MODELS`
  (`lib/tenant/scopeProxy.ts:96-98` pass-through). WIOA report
  `take: 10000` is the exhibit.
- **Apply signup is the real default-org write.** First beat blamed the
  healer (`ensureAppUserProvisioned`). The conversion path itself stamps
  `workforceap` at `app/api/apply/signup/route.ts:367`.

  covered authed apply/AI/voice. Public WIOA mint has no `getUser`.
- **SSR vs API split.** Member export API is scoped; `/admin/members`
  HTML is not. CI tenant grep never opens `page.tsx`.
- **Employer/counselor/partner `take: 5000` and admin counselors `take: 20000`.**
  First beat only counted training-progress.
- **Super-admin fallback upserts + any-tenant `findFirst`.** Not in the
  161-file map.
- **GDPR delete does not touch storage.**
- **CI lint/vitest advisory; `RATE_LIMIT_ALLOW_MISSING_UPSTASH=1` in CI.**
