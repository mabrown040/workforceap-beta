## Priority 1 — Score Blockers (must-fix for 85+)

### P1-1: Fix keyword density / thin content on apply pages
- **Issue:** `/apply?program=*` pages flag for keyword stuffing (`career` 3.1%, `workforceap` 3.1%, `certificate` 4.3%) and thin content (184 words, min 300)
- **Fix:** Add unique program-specific intro text (50–100 words) to each program apply page, pulled from the program data. Reduces keyword density + meets word count.
- **Files:** `app/apply/page.tsx`, `app/apply/ApplyEligibilityClient.tsx`, `lib/content/programs.ts`
- **Effort:** ~45 min

### P1-2: Add program-specific meta titles/descriptions to /apply?program= pages
- **Issue:** 34 pages share same title/description — squirrel flagged as duplicate titles affecting SEO
- **Fix:** Dynamically generate `<title>Apply for [Program Name] — WorkforceAP</title>` and unique `<description>` per program slug
- **Files:** `app/apply/page.tsx`
- **Effort:** ~30 min

### P1-3: Add canonical URLs to /apply?program=* and /program-comparison?compare=* pages
- **Issue:** Parameterized pages without canonical may get devalued as duplicates
- **Fix:** Add `alternates.canonical` pointing to the base `/apply` and `/program-comparison` for paginated variants, or add per-program canonicals
- **Files:** `app/apply/page.tsx`, `app/program-comparison/page.tsx`
- **Effort:** ~20 min

### P1-4: Fix `noindex` conflict on 3 pages with rich schema
- **Issue:** squirrelscan flagged 3 pages with structured data but `robots: noindex` — schema is wasted
- **Fix:** Either remove schema from noindex pages or flip them to indexable (if intentional)
- **Files:** Check which pages — likely `/login`, `/employer` (auth-gated, noindex is correct → remove schema)
- **Effort:** ~20 min

### P1-5: Add more internal links to orphaned program pages
- **Issue:** 23 program pages have only 1 incoming internal link — hurts crawlability and page authority
- **Fix:** On `/programs` index, link each program card to its detail page (likely already done) AND add "Related programs" section at bottom of each program detail page
- **Files:** `app/programs/[slug]/page.tsx`, `lib/content/programs.ts`
- **Effort:** ~45 min

### P1-6: Fix heading hierarchy on apply/program-comparison pages
- **Issue:** Squirrel detected H2→H4 skips on 53 pages
- **Fix:** Audit heading levels in program comparison client and apply flow — ensure no heading levels are skipped
- **Files:** `app/program-comparison/ProgramComparisonClient.tsx`, `app/apply/ApplyEligibilityClient.tsx`
- **Effort:** ~30 min

## Priority 2 — Design Fixes (deferred from /design-review)

### P2-1: Break the 3-column AI slop feature grid on homepage
- **Issue:** "Industry Certs / Loaner Laptop / Job Placement" section uses the canonical AI-generated 3-column card layout
- **Fix:** Redesign as a horizontal feature list with large icons on left + text on right, OR use an asymmetric 2+1 layout (lead feature large, two supporting smaller)
- **Files:** `app/page.tsx`, `css/main.css`
- **Effort:** ~60 min

### P2-2: Apply page hero/callout visual weight fix
- **Issue:** Dark hero + gray callout box creates a visual wall before the form
- **Fix:** Lighten "Where we operate today" callout, or use a subtle green-tinted card instead of gray. Add breathing room between hero and form.
- **Files:** `app/apply/page.tsx`, `css/main.css`
- **Effort:** ~30 min

### P2-3: Leadership "FOUNDER" badge positioning
- **Issue:** Badge overflows the photo container differently than other cards
- **Fix:** Ensure badge is `position: absolute` relative to card wrapper, not photo element
- **Files:** `css/main.css` (leadership styles)
- **Effort:** ~15 min

### P2-4: Blog post thumbnails — replace logo placeholder
- **Issue:** Every blog post shows logo as thumbnail — looks repetitive and untrustworthy
- **Fix:** Use a default OG image per category, or pull the post's hero image. Add `coverImage` field to blog schema if missing.
- **Files:** `app/blog/BlogListingClient.tsx`, `prisma/schema.prisma` (if field needed)
- **Effort:** ~45 min
