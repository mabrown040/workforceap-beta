  older than 15 minutes. Successful status alone is insufficient where a handler
  previously hid delivery failures; the fixes above address reproduced cases.
- Of 126 active application profiles, four lacked Auth identities. All four
  matched explicit seed/test accounts in repository sources; no additional
  unexplained identity gap was found by this check. There were no active
  application/Auth email mismatches, active profiles pointing to deleted Auth
  identities, or duplicate normalized active email groups. No fixture identities
  were created in production.
- Eight completed daily backups were observed. The latest was September 9
  around 09:54 UTC; point-in-time recovery was disabled. This is backup metadata
  evidence, not a successful restore test. See [Database recovery](../DATABASE-RECOVERY.md).

  creation. Historical migration files were not rewritten and production was
